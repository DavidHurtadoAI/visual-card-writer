# Contributing

Thanks for helping improve Visual Card Writer.

## Reporting a bug

Before opening an issue, check that the problem still occurs with the latest release and that another plugin is not causing the conflict. Include:

- Obsidian and Visual Card Writer versions.
- Operating system.
- A minimal Markdown example that reproduces the problem.
- Exact steps, expected result, and actual result.
- A screenshot or short recording when the issue is visual.

Remove private information from notes and diagnostics before posting them.

## Development workflow

1. Fork the repository and create a focused branch.
2. Install dependencies with `pnpm install`.
3. Make the smallest coherent change.
4. Add or update tests where practical.
5. Run `pnpm run check` before opening a pull request.

Keep pull requests focused and explain any user-visible behavior change.
